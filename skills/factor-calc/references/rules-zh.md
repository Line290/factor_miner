# 量化策略数据取数避坑规范（中文详细版）

> **一句话原则：Point-in-Time（时间点正确）。**
> 策略在 `t` 日能"看到"的数据，只能是截至 `t` 日收盘/披露后**真实可得**的数据。
> 凡是用了 `t` 日之后才存在的信息（价格、财报、宏观、成分股、修订值……），都是前视偏差，
> 都会让回测变成"用未来预测过去"，实盘必然失效。

## 一、行情数据：必须使用复权价

**默认规则：技术信号与收益率一律用复权价，不要用不复权（原始）价。**

| 复权方式 | 含义 | 适用场景 | 注意 |
|---|---|---|---|
| 前复权 | 以**最新交易日**的复权因子为基准，将所有历史价格按复权因子等比例缩放，使最新价等于真实市价 | 看盘、画线、技术形态、指标连续性 | 历史价非真实成交价 |
| 后复权 | 以**历史某日**为基准，向后累积调整 | 长期真实收益、含分红再投资的净值对比 | 当前价 ≠ 真实市价 |
| 不复权 | 真实成交价，但有除权除息缺口 | 需要真实成交价/真实成交额的场景 | 缺口会让收益率与指标失真 |

避坑要点：

1. 不复权价存在除权除息跳空缺口，会让收益率在除权日出现虚假暴涨/暴跌，MA、MACD、布林带、RSI 等全部失真。
2. **回测中不要混用口径**：用复权价算信号与收益；若需真实成交价/成交额，单独取不复权字段并显式标注，二者不可直接相减或拼接。
3. **复权因子本身有延迟**：除权公告日 ≠ 执行日，回测时要确认所用复权因子在回测时点已经可得，不能在除权发生前就"预知"新因子。
4. 期货/可转债等：主力连续合约换月会产生跳变，需用复权连续合约或显式处理换月，否则出现虚假价差。
5. 若策略依赖分红再投资，要明确在回测中是否假设"分红当日再投入"，口径前后一致。
6. 前复权下，**除权除息日之前的历史价格会被压低**（分红场景），会导致基于历史价格的绝对价位策略（如"股价低于 20 元的低股价策略"）产生严重偏差。

## 二、财务数据：取「公布日」，不取「报告期日」

核心区分：

- **报告期日**（如 2023-12-31）：财务数据所属的会计期间末尾。
- **公布日 / 披露日**（如 2024-04-20）：该报告实际对外发布的日期。

**在报告期日就使用数据 = 提前"知道"了尚未发布的财报 = 严重前视偏差。**

避坑要点：

1. 财务数据要按**披露日期**对齐到回测时间轴，而不是按报告期。策略在 `t` 日只能使用截至 `t` 日已披露的财务数据。
2. 注意法定披露时限带来的"财报真空期"：
   - 一季报：当年 4/30 前
   - 中报：当年 8/31 前
   - 三季报：当年 10/31 前
   - 年报：次年 4/30 前（个别可延至 6 月）
   在真空期内，应使用**最近一次已披露**的报告期数据（如 8 月用一季报，不能用尚未披露的中报）。
3. **业绩预告/快报/正式报告**是不同信息层级：快报早于正式报告，可作为早期信号但必须标注层级，不能用正式报告的终值去对齐快报时点。
4. 警惕**财报修正与追溯调整**（差错更正）：回测要用当时披露的原始版本，不能用后来更正后的"干净"版本。
5. TTM/滚动指标要基于**已披露的最新报告期**滚动推算，不能跨入尚未披露的季度。
6. 字段口径要分清：归母净利润 vs 扣非净利润、ROE 加权 vs 摊薄、营收是否含追溯重述等。
7. 分红除息日的精确时点：股权登记日、除权除息日、红利发放日是三个不同日期。分红再投资应在除权除息日当日以除权后的价格再投入，而非红利发放日。

## 三、宏观数据：取「公布日」，且用「当时可得版本」

核心区分：指标所属期（如 CPI 的 2023-03）≠ 公布日（通常次月 9–15 日左右）。

常见宏观指标的典型公布延迟（A 股口径，仅供参考，以官方为准）：

| 指标 | 大致公布时点 | 备注 |
|---|---|---|
| PMI | 次月 1 日前后 | 月初即发布 |
| CPI / PPI | 次月 9–15 日 | 常有基期调整 |
| 社融 / 信贷 | 次月 10–15 日 | 央行口径 |
| M1 / M2 | 次月 10–15 日 | 央行口径 |
| 工业增加值 | 次月约 15 日 | — |
| GDP | 季度后约 15–20 日（初值），后续多次修订 | 年度有大修 |

避坑要点：

1. 宏观指标通常滞后 1–2 个月，**必须用公布日对齐**，不能用所属期日就把数据"提前"放进回测。
2. 宏观数据普遍经历**初值 → 终值 → 修订**：回测要用**当时可得的初值版本**，不能用今天的修订终值（否则前视）。
3. 多源口径不一致（统计局、央行、第三方平台），**全策略统一单一权威来源**，避免不同指标混用不同口径。
4. 注意数据修订窗口（GDP 年度修订、CPI 基期轮换），这些修订会事后改写历史值，破坏 point-in-time。

## 四、数据日期：严格使用需在「当前日期 − 1 天」

规则：当日（T 日）发布的数据，在严格回测中默认 T 日不可用于成交，最早 T+1 才可得、可交易。

避坑要点：

1. 行情：T 日收盘价在 T 日收盘撮合后才最终确定；盘中数据是部分快照，不能拿盘中价当"收盘价信号"并在同日成交。
2. 财务/新闻/公告：多在盘后发布，T 日信号应约定为 T+1 成交（或盘后决策、下一交易日执行）。
3. **信号日 = 数据可得日；成交日 = 信号日 + 最小延迟（通常 T+1）。** 不要把"T 日收盘出信号、T 日收盘成交"作为默认设定，除非明确建模了盘后决策 + 次日成交。
4. 注意特殊交易时段：夜盘、集合竞价、盘后固定价格交易，其"当日"边界与信号可得性要单独定义。
5. 实操建议：数据查询的 `end_date` 默认取 `today - 1` 天；若确需含当日，必须显式说明并接受"该数据不可用于当日成交"的约束。

## 五、均值/趋势/截面类指标：严禁未来数据

凡是"统计窗口/归一化分母"包含当前时点之后样本的，都是未来函数。

避坑要点：

1. 移动平均（MA）、指数平滑（EWMA）、回归趋势线、波动率（滚动标准差）、布林带、RSI、ATR 等：**窗口右边界必须 ≤ 当前回测日**，不能让未来 N 日数据参与计算。
2. **截面标准化**（z-score、分位排名、行业中性化、市值中性化）：
   - 分母（全市场均值、标准差、市值）必须用**截至当前时点的横截面**数据；
   - 不能包含未来才上市/才纳入的股票，也不能用全样本（含未来）统计后回填。
3. **因子值的所有输入变量必须在信号日已可得**：引用了次日收益率、未来财报、未来成分股的因子直接作废。
4. **指数成分股/行业分类要用信号时点的版本**：成分股定期调整、行业重分类是未来事件，用"现在的成分股"去回测过去会产生前视与幸存者偏差。
5. 横截面选股（如"全市场排名前 10%"）：排名池必须是当时全部可交易股票（含后来退市的），不能隐含用未来存活状态筛选。

## 六、其他高频陷阱清单（回测前逐项核对）

- **生存偏差（Survivorship Bias）**：回测股票池只含当前存续个股，漏掉已 ST、已退市的，会系统性高估收益。必须纳入历史全部上市标的及其退市/摘牌状态。
- **退市/摘牌处置**：退市股最后交易日后无价格，需明确规则（按退市价、归零、或剔除并计算处置收益），不能静默丢弃导致收益虚高。
- **涨跌停无法成交**：涨停买不进、跌停卖不出。按收盘价无约束成交是虚假的，需加"当日是否达到涨跌停、是否可成交"约束。
- **ST 股票涨跌幅限制变化**：ST 股票涨跌幅限制从 10% 变为 5%，回测中需动态判断涨跌停阈值，不能固定用 10% 或 5%。
- **停牌无法交易**：停牌期间无法调仓，回测需锁定持仓、顺延交易指令，不能假设随时可买卖。
- **流动性/冲击成本**：低流动性小市值策略冲击成本极大；需设成交量约束（如仅成交当日成交量的某比例）与滑点模型，不能假设无限容量。
- **交易成本低估或漏计**：佣金、印花税、过户费、滑点、冲击成本。未计入费用的回测收益不可信。
- **过拟合/数据窥探**：样本内过度优化、参数网格搜索、多重检验（multiple testing）。用样本外、滚动窗口、Walk-forward 验证，惩罚复杂度，控制名义检验数量。
- **数据频率错配**：日频因子用于分钟级决策、不同频率拼接错位，需明确对齐与回填规则。
- **异常值/缺失值处理**：停牌导致的 0/NaN、极端值，填充方式需谨慎并标注：前向填充（ffill）不引入未来信息但可能掩盖停牌信号；后向填充（bfill）会引入未来信息，严禁使用。
- **财报季节性**：同比/环比基数差异因行业和报告期而异，口径要一致，跨期比较时需做季节性调整。
- **基准选择**：用正确的市场基准（沪深 300/中证 500/中证全指等），避免幸存者基准。
- **时间戳与时区**：跨市场、夜盘、数据落地时间差，统一时区与"交易日"定义。
- **数据回填（Backfill）陷阱**：第三方接口返回的历史数据往往已含后来修订值，破坏了 point-in-time，回测前要确认接口是否提供历史时点快照。
- **新股/次新股上市首日数据**：新股上市首日无历史复权数据，且涨跌幅限制不同（前 5 日不设涨跌幅限制），回测中需特殊处理，否则会产生虚假信号。
- **机器学习场景**：训练集/验证集/测试集不能随机 shuffle，必须按时间顺序划分（如 TimeSeriesSplit）。标签（label）的生成同样需要避免前视偏差（如用未来收益率作为标签需确认该收益率在特征生成时点是否可得）。
- **数据源一致性**：不同数据源（Wind、同花顺 iFinD、东方财富、通达信、聚宽、Tushare）对同一指标的计算口径可能不同（如市值计算用总股本还是自由流通股本、行业分类标准不同等），全策略必须统一数据源。
- **回测中的"未来函数"隐蔽形式**：用全样本最优参数（full-sample optimal parameters）；用未来状态确定行业中性化分组（如用现在的行业分类对历史数据做中性化）；用未来已知的停牌/涨跌停状态做特征工程。
- **对数收益率 vs 简单收益率**：对数收益率（ln(Pt/Pt-1)）具有时间可加性（多日对数收益率 = 各日对数收益率之和），而简单收益率不具有时间可加性（不能直接相加，需通过连乘方式聚合）。选择不同会影响多日累计收益率的计算，需统一口径。
- **年化处理的正确方式**：日频收益率年化时，简单收益率年化 = (1+日收益率)^252 − 1，对数收益率年化 = 日对数收益率 × 252。混用会导致年化收益偏差。
- **截面标准化中的缩尾处理（Winsorize）**：在截面标准化前，通常需要对因子值进行缩尾处理（如 3σ 缩尾或分位数缩尾），以消除极端值对标准化结果的影响。
- **滚动窗口中的缺失值/停牌处理**：当滚动窗口内某股票停牌（数据为 NaN），`rolling().mean()` 的行为取决于 `min_periods` 参数设置。若 `min_periods` 过小，会用少量有效数据计算，导致指标失真；若过大，则停牌后指标长时间不更新。应明确约定 `min_periods` 策略。
- **北向资金/龙虎榜等资金流数据可得性**：北向资金在交易日 18:00 前由交易所公布，龙虎榜在 16:30 后公布。若策略在盘后使用这些数据生成次日信号，需确认数据在信号生成时点已可得，部分数据源可能延迟到次日早晨才更新。
- **绩效评估的时点问题**：夏普比率中的无风险利率取值时点需与回测日对齐，不能用当前无风险利率回溯计算历史夏普比率；最大回撤应在全回测窗口内计算，不能只算样本内。
